# Security policy

Please do not report vulnerabilities in public GitHub issues.

Email the repository owner through the contact details on their GitHub profile. Include a concise reproduction, affected version or commit, impact, and any suggested mitigation. We will acknowledge reports within seven days and coordinate a fix before public disclosure when practical.

This repository is a reference implementation. Its sample endpoints do not include authentication, authorization, or a complete financial ledger. Do not expose them directly to the public internet without adding those controls.
